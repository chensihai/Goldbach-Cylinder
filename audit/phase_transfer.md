# CRT phase-transfer discovery audit

The exact data is generated by:

```text
python3 scripts/audit_phase_transfer.py
```

The audit tests the phase

```text
h = ((delta_q - delta_p) * P^{-1}) mod Q
```

and the wrap bit recording whether the canonical CRT quotient for `n` is
smaller than the quotient for `k`.

## Results

- The phase histogram obeys the predicted affine transfer exactly in every
  tested case:
  `h -> p^{-1}(h-d) mod Q`, with multiplicity `p-d`.
- Phase alone does not determine ordinary order.  In `(3,5;1,1)`, four of the
  five occupied phases contain both positive and negative order contributions.
- `(h,wrap)` determines the current order kernel, with the local `p` difference
  resolving the `h=0` diagonal case.  It is not closed under digit extension.
  Even after fixing `(h,wrap,a,b)`, both successor wrap values occur.  The
  nonclosed-key counts are `25/54`, `321/492`, and `115/195` in the representative
  `(3,5;1,1)`, `(3,7;1,2)`, and `(5,7;1,1)` cases.
- A closed exact state therefore needs an absolute CRT anchor, for example
  `(c_k,h)`, unless common translations can first be eliminated analytically.
- Shifting both q-coordinates through every common relative alignment does not
  produce a zero-mean defect.  The tested shift sums are `55`, `375`, `22393`,
  and `343`; the detailed shift vectors are in `phase_transfer.json`.

The phase walk is a genuine closed marginal with the expected Lucas mass, but
the order observable is not a function of that marginal.  A future transfer
operator should act on an anchored phase state and only then seek a quotient or
Fourier decomposition that removes the translation coordinate.
